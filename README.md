# Eredon KoV
Windows desktop version of Knights of Valor (Eredon). Download the latest installer from the Releases page:
https://github.com/Alchadius/Eredon-KoV/releases/latest/download/Eredon-KoV-Setup.exe

- `game/` — the game itself (updated in-app via the Update button)
- `app/` — Electron shell + installer config
- `tools/sigserver.js` — optional self-hosted matchmaker (testing/fallback)
